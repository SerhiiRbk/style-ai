# Valetti Metals SVG Set

All assets use the same `256 × 256` viewBox and a circular swatch centred at `(128, 122)` with radius `100`.

## Cool

- Silver — `valetti-silver.svg`
- Brushed steel — `valetti-brushed-steel.svg`
- White gold / platinum — `valetti-white-gold-platinum.svg`
- Avoid bright yellow gold near the face — `valetti-avoid-bright-yellow-gold-v2.svg`

## Warm

- Yellow gold — `valetti-yellow-gold.svg`
- Brass / bronze — `valetti-brass-bronze.svg`
- Cognac leather — `valetti-cognac-leather.svg`
- Avoid bright chrome / cool silver next to the face — `valetti-avoid-cool-chrome-v2.svg`

## Neutral

- Soft gold — `valetti-soft-gold.svg`
- Steel — `valetti-steel.svg`
- Two-tone — `valetti-two-tone.svg`
- No hard avoid rule; keep one dominant tone.

## Colour DNA mapping

- `warm` → `valetti-yellow-gold.svg` or `valetti-brass-bronze.svg`
- `cool` → `valetti-silver.svg` or `valetti-steel.svg`
- `neutral` → `valetti-soft-gold.svg` or `valetti-steel.svg`
